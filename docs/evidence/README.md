The browser test fails if the two-viewer interruption exceeds 500 ms. Its timing is a local sample, not an OBS capture or production network benchmark. Node tests separately advance an injected clock through playback deadlines and far beyond the old scene's end, checking that stale playback cannot return. Browser tests also check refresh recovery and offline board/clock retention.

Chromium screenshots were visually reviewed at 1080p and 720p. OBS itself, an eight-hour rehearsal and the PRD's five-person comprehension check have not been run. Node's built-in SQLite currently emits an experimental-feature warning on the local runtime; the application otherwise runs without runtime warnings of its own.
